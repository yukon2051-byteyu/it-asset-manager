# 社内IT資産管理システム

PC・モニター・スマートフォン・ソフトウェアライセンスを1か所で管理する、社内向けのWebアプリです。
Excel台帳による手作業の管理を置き換えることを目指して開発しています。

> **開発中**：現在は「資産一覧の表示と絞り込み」と「自分の資産の確認」まで動作します。開発の状況は「[開発の状況](#開発の状況)」を参照してください。

## 解決したい業務課題

IT資産をExcelの台帳で管理している職場で、次のような課題が起きることを想定しています。

| 課題 | このシステムでの解決方法 |
|---|---|
| 台帳の更新漏れ・二重登録が起きる | データベースで一元管理し、資産番号・シリアル番号の重複を登録時に防ぐ |
| 「誰が・どの機器を使っているか」をすぐ答えられない | 機器と利用者をひも付けて、一覧で絞り込めるようにする |
| ライセンスの保有数と利用数が合わない | 割当の記録から残数を自動で計算する |
| 貸出・返却の記録が残らない | 申請・承認をシステム上で行う（予定） |
| 棚卸に時間がかかる | 社員が画面で回答できるようにする（予定） |

※ 上記は一般的な業務を想定した課題です。特定の企業での実測や導入の実績ではありません。

## 使い方（Windows）

### 1. 環境を作る（初回のみ）

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 2. サンプルデータを入れる（初回のみ）

```powershell
.\.venv\Scripts\python.exe seed.py
```

架空の社員5名・機器10台・ライセンス3種類が登録されます。データがすでにある場合は、何もせずに終了します。

### 3. アプリを起動する

```powershell
.\.venv\Scripts\streamlit.exe run app.py
```

ブラウザで http://localhost:8501 が開きます。
- **一般社員**：画面左側の「（仮）ログイン中の社員」で社員を選ぶと、その人の機器とライセンスが表示されます
- **IT管理者**：画面左側で「IT管理者」→「資産一覧」を選ぶと、全機器を絞り込んで表示できます

終了するときは、ターミナルで `Ctrl + C` を押します。

## 設計で工夫した点

- **データを1か所でだけ持つ**：ライセンスの残数は保存せず、割当の記録から毎回計算します。残数を別に保存すると、更新漏れで数字が食い違うためです
- **入力ミスはデータベース自体で防ぐ**：重複・空欄・決められていない値は、プログラムに不具合があってもデータベースが受け付けません
- **保存する値と表示する名前を分ける**：状態は `in_use` などのコードで保存し、画面では「使用中」と表示します。表示名を変えても保存済みのデータに影響しません
- **機器を1つのテーブルにまとめる**：PC・モニター・スマートフォンを1つの表にまとめ、「ある社員の機器をすべて見る」処理を簡単にしました。種別によって空欄の列ができる点は許容しています
- **データを物理削除しない**：廃棄した機器も記録として残します（監査に対応するため）
