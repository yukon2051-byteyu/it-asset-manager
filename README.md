# 社内IT資産管理システム

PC・モニター・スマートフォン・ソフトウェアライセンスを1か所で管理する、社内向けのWebアプリです。
Excel台帳による手作業の管理を置き換えることを目指して開発しています。

> **開発中**：現在は「ログイン」「資産一覧の表示と絞り込み」「資産の登録・更新」「割当・返却・廃棄」「自分の資産の確認」まで動作します。開発の状況は「[開発の状況](#開発の状況)」を参照してください。

## 解決したい業務課題

IT資産をExcelの台帳で管理している職場で、次のような課題が起きることを想定しています。

| 課題 | このシステムでの解決方法 |
|---|---|
| 台帳の更新漏れ・二重登録が起きる | データベースで一元管理し、資産番号・シリアル番号の重複を登録時に防ぐ |
| 「誰が・どの機器を使っているか」をすぐ答えられない | 機器と利用者をひも付けて、一覧で絞り込めるようにする |
| ライセンスの保有数と利用数が合わない | 割当の記録から残数を自動で計算する |
| 貸出・返却の記録が残らない | 申請・承認をシステム上で行う（予定） |
| 棚卸に時間がかかる | 社員が画面で回答できるようにする（予定） |

※ 上記は一般的な業務を想定した課題です。特定の企業での実測や導入の実績ではありません。

## 使い方（Windows）

### 1. 環境を作る（初回のみ）

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 2. サンプルデータを入れる（初回のみ）

```powershell
.\.venv\Scripts\python.exe seed.py
```

架空の社員5名・機器10台・ライセンス3種類が登録されます。データがすでにある場合は、何もせずに終了します。

実行すると、社員ごとのログイン用パスワードが**1回だけ**表示されます。パスワードは実行のたびにランダムに作られ、ソースコードには書かれていません。

```
  E0001  佐藤 花子（IT管理者）  ************
  E0002  鈴木 一郎（一般社員）  ************
  ...
```

パスワードを忘れた場合は、`assets.db` を削除してから `seed.py` を実行し直してください（サンプルデータも作り直されます）。

### 3. アプリを起動する

```powershell
.\.venv\Scripts\streamlit.exe run app.py
```

ブラウザで http://localhost:8501 が開きます。社員番号と、手順2で表示されたパスワードでログインしてください。
- **一般社員**（例：E0002）：「自分の資産」に、自分が使っている機器とライセンスが表示されます
- **IT管理者**（E0001）：「資産一覧」で、全機器を種別・状態で絞り込んで表示できます。「資産登録」で新しい機器を登録し、「資産更新」で登録済みの機器の情報を変更できます。「割当・返却・廃棄」で機器の状態を変えられます

終了するときは、ターミナルで `Ctrl + C` を押します。

## 設計で工夫した点

- **データを1か所でだけ持つ**：ライセンスの残数は保存せず、割当の記録から毎回計算します。残数を別に保存すると、更新漏れで数字が食い違うためです
- **入力ミスは2段構えで防ぐ**：画面で登録するときに、わかりやすいメッセージで入力ミスを知らせます。さらにデータベース自体にもルールを設けているので、プログラムに不具合があっても重複・空欄・決められていない値は保存されません
- **状態は自由に書き換えさせない**：資産の更新画面では、状態（使用中・廃棄済など）と利用者は変更できません。状態は割当・返却・廃棄などの業務の操作でだけ変わるようにし、「利用者がいないのに使用中」といった矛盾を防ぎます。操作できる状態の組み合わせは1つの表（`devices.TRANSITIONS`）にまとめ、要件定義書の状態遷移図と対応させています
- **同時操作に備える**：状態を変えるときは「画面を開いたときの状態のままなら更新する」という条件を付けています。ほかの管理者が先に変えていた場合は、上書きせずに止めます
- **資産番号を使い回さない**：番号は自動で発行し、廃棄した機器の番号も欠番として残します。過去の記録と新しい機器が混ざらないようにするためです
- **保存する値と表示する名前を分ける**：状態は `in_use` などのコードで保存し、画面では「使用中」と表示します。表示名を変えても保存済みのデータに影響しません
- **機器を1つのテーブルにまとめる**：PC・モニター・スマートフォンを1つの表にまとめ、「ある社員の機器をすべて見る」処理を簡単にしました。種別によって空欄の列ができる点は許容しています
- **パスワードを安全に扱う**：パスワードはそのまま保存せず、社員ごとに違うランダムな値（ソルト）を混ぜて60万回変換した文字列だけを保存します（Python標準の `hashlib.pbkdf2_hmac`）。ログインに失敗したときは「社員番号**または**パスワードが違います」とだけ表示し、どちらが違うかは伝えません
- **データを物理削除しない**：廃棄した機器も記録として残します（監査に対応するため）
